# EVOLVE YOUR WORLD – המשחק ברובלוקס

כל המשחק כתוב כאן בקוד, לפי המסמך של אדם: השטיח האדום, הריבוע השחור, 10 בייסים, המכונות הירוקות, הקרן, הכדור, הכסף, השמירה, ו־12 הדמויות.

## איך פותחים את המשחק (הכי פשוט)

1. מורידים את הקובץ `roblox/EvolveYourWorld.rbxlx` מ־GitHub (כפתור Download).
2. לוחצים עליו פעמיים. הוא נפתח ב־Roblox Studio.
3. לוחצים **Play** למעלה. העולם כולו נבנה לבד: השטיח, הבייסים, הכדורים והדמויות.

כדי שהשמירה תעבוד בתוך Studio:
**Game Settings ← Security ← Enable Studio Access to API Services = ON** (קודם צריך לשמור את המשחק לרובלוקס עם File ← Publish to Roblox).

כדי שיהיו 10 שחקנים בשרת: **Game Settings ← Places ← Server Size = 10**.

## מה יש במשחק

| דבר | איך זה עובד |
|---|---|
| שטיח אדום | כל שנייה יוצאת דמות מהריבוע השחור. איזו דמות, לפי האחוזים במסמך |
| קנייה | ניגשים לדמות ולוחצים E. היא הולכת לבייס שלך. שחקן אחר יכול לקנות אותה בדרך, ואז אתה מקבל את הכסף בחזרה |
| מכונה ירוקה | הדמות נכנסת למכונה פנויה וישנה שם, תלויה על חוט |
| כפתור אדום | יורה קרן לכדור, ובתוך הכדור נוצר העולם של הדמות. מאותו רגע היא מרוויחה כסף כל שנייה |
| משטח ירוק | הכסף מצטבר עליו. עומדים עליו ומקבלים את הכסף |
| משטח כחול | קונים מכונה נוספת (7 עד 10). כל מכונה גם מגדילה את הכדור |
| מכירה | ליד המכונה, מחזיקים F. מקבלים 90% מהמחיר |
| שמירה | הכסף, המכונות ומה שבתוך כל מכונה. כשלא משחקים מרוויחים 10%, עד שעתיים |
| פעם ראשונה | אנימציה של הכדור, ואז חץ צהוב שמראה מה לעשות |

כל המספרים (מחירים, רווחים, מהירות) נמצאים בקובץ אחד: `src/shared/Config.luau` ו־`src/shared/ItemData.luau`.

## Robux

כדי למכור מכונות ב־Robux: יוצרים Developer Product לכל מכונה ב־Creator Hub, ומדביקים את המספר שלו ב־`MachineRobuxProducts` בקובץ `Config.luau`. עד אז המשחק פשוט אומר כמה כסף חסר.

## איפה כל דבר

| קובץ | מה יש בו |
|---|---|
| `src/shared/Characters/` | 12 הדמויות, קובץ לכל דמות |
| `src/shared/Gait.luau` | איך כל דמות הולכת |
| `src/server/Map.luau` | בניית העולם: שטיח, ריבוע שחור, בייסים, מכונות, כדור |
| `src/server/Main.server.luau` | חוקי המשחק: יציאת דמויות, קנייה, קרן, כסף, שמירה |
| `src/client/SphereWorld.luau` | מה שגדל בתוך הכדור לכל דמות |
| `src/client/WalkFx.luau` | אפקטי ההליכה (נצנצים, אדמה, כסף, עשן, אש) |
| `src/client/Main.client.luau` | הכסף על המסך, הודעות, החץ, אנימציית הפתיחה |

## למפתחים

- אחרי שינוי בקוד, בונים מחדש את קובץ המשחק: `python3 roblox/tools/build_place.py`
- אפשר גם לעבוד עם Rojo (`rojo serve roblox/default.project.json`).
- תצוגת הדמויות בדפדפן (`labs/characters/`) נבנית מאותו קוד: `python3 roblox/tools/preview/export.py && python3 roblox/tools/preview/build.py` (צריך `redis-server` מותקן).
